# Security Policy

This repository (`fitzyracing1/api-docs`) is a personal fork of [nasa/api-docs](https://github.com/nasa/api-docs), maintained by Joshua Almeida ([@fitzyracing1](https://github.com/fitzyracing1)).

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub issues, discussions, or pull requests.

Instead, report them privately to the fork maintainer, Joshua Almeida, using GitHub's
[private vulnerability reporting](https://github.com/fitzyracing1/api-docs/security/advisories/new)
for this repository.

Please include as much of the following as you can:

- The type of issue (e.g. injection, credential exposure, insecure configuration)
- The affected file(s), branch, or commit
- Step-by-step instructions to reproduce the issue
- Proof-of-concept or exploit code, if available
- The potential impact of the issue

You can expect an acknowledgement within 7 days. Please allow reasonable time for a fix before any public disclosure.

If the issue also affects the upstream project, please report it to NASA through the
upstream repository's own security policy as well.

## Supported Versions

Only the latest commit on this fork's default branch is supported with security fixes.
